# Artificial-Neural-Networks

This repository contains assignments, tutorials, and implementations related to Artificial Neural Networks using PyTorch.

## Contents

- **Assignment 1**: Introduction to PyTorch, neural networks basics, Fashion-MNIST, transfer learning
- **Assignment 2**: Convolutional Neural Networks (CNNs), batch normalization, LeNet
- **ANN-assignment**: Advanced topics including autoencoders, embeddings, RNNs, sentiment analysis, and language translation
- **Pytorch_MNIST**: MNIST digit classification with PyTorch
- **intro-to-pytorch**: PyTorch fundamentals and tutorials

## Azure Integration

- **list_load_tests.py**: Script to list Azure Load Tests for a subscription
- **requirements-loadtest.txt**: Dependencies for Azure Load Testing integration
- **LOADTEST_README.md**: Documentation for Azure Load Testing features

## Development Tools

- **[MCP_SERVERS.md](MCP_SERVERS.md)**: Documentation about Model Context Protocol (MCP) servers available in the development environment

## Getting Started

### Prerequisites

- Python 3.8+
- PyTorch
- Jupyter Notebook

### Installation

```bash
pip install torch torchvision jupyter numpy matplotlib
```

For Azure Load Testing features:
```bash
pip install -r requirements-loadtest.txt
```
